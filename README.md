# Dino Game 🦖

A simple endless runner game inspired by the Chrome Dino Game, built using C++ and SFML. Jump over obstacles, survive as long as possible, and try to beat your high score.

---

## Features

- Smooth player movement and jumping
- Endless scrolling background and ground
- Random cactus obstacles
- Score system
- Pause functionality
- Sound effects
- Game over screen
- FPS limited for smooth gameplay

---

## Controls

| Key | Action |
|------|--------|
| Space | Jump |
| Escape | Pause / Resume |
| Delete | Exit Game |

---

## Technologies Used

- C++
- SFML Graphics
- SFML Audio
